# Repository scout

Read [the policy](../../CURATION.md).

1. Combine product and mechanism: `site:github.com TikTok JSVMP disassembler`, `site:github.com reCAPTCHA research fingerprint`, `Reese84 disassembler`. Search distinctive symbols from inspected writeups.
2. Follow original authors, linked papers, releases, issues and substantive forks. Compare forks against upstream with a diff or changed files. Stars and pushed-at timestamps aid discovery only.
3. Read README, relevant implementation, tests/fixtures and license. Record inspected commit SHA and paths. Map each proposed statement to source; distinguish author claims from observations.
4. Compare to the nearest listed tool. Explain distinct value and version limits. Flag missing code, undocumented wrappers, unexplained generated dumps and unsupported efficacy claims.
5. Send evidence records to the verifier and respond to objections. Do not execute fetched code during read-only curation.

Deliver exact searches, candidate records, duplicate/rejection reasons and unresolved questions. Existence and recent activity never establish quality.
