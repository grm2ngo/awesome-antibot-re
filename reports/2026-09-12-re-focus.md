# Restore implementation RE — 2026-09-12

## Why this correction was needed

The owner pointed out that an anti-bot RE catalogue had lost most of its RE. The 1.0 migration put implementation case studies behind legacy/history while foregrounding general fingerprint concepts and service integration. Its rule that captured vendor versions belong in a separate historical file amplified this mistake. This is an owner-requested editorial correction, not a claim that an hourly or daily discovery run completed.

Policy 1.1 keeps the 85-point threshold and mandatory evidence gates, adds target/method/artifact requirements for the main list, and allows explicitly bounded snapshot research. Age alone does not disqualify an RE method. An obsolete implementation still cannot be advertised as a current tool. Supporting references remain curated separately; no previous curated resource was deleted.

## Skeptical review and corrected claims

1. BMP: the decoder comment treats the FUNC operand as a body length, but the writeup says its semantics are unresolved. The description now says partial disassembly; the old legacy “working” wording is not repeated.
2. XP1M: byte-for-byte reproduction is an author claim with a private engine, not a result independently obtained by this catalogue.
3. AWS WAF: `main.js` loads ten transforms; the extra dead-condition simplifier described in README is not loaded there. Selection is for inspecting the staged driver, not current compatibility.
4. Trip.com: the “taint analysis” heading describes logging and reconstruction. The inspected Proxy/watch setup is commented out. The catalogue uses the narrower term handler tracing.
5. Douyin: the README's 2026-08-30 date identifies the captured version; it should not automatically be treated as article publication or substantive update. Keep it as a version-bounded snapshot unless a distinct publication date is established.
6. English content in a repository named FamousRussianMarketplace is English-language evidence; it is not Russian-language coverage or evidence of author nationality.
7. A Turnstile fork shares upstream source and its nonfunctional notice. A long maintenance guide is not proof that its suggested repairs, update cadence or opcode claims are correct.
